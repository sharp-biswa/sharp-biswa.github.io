A high-performance personal portfolio built for **Biswaranjan Sahoo**, B.Tech Computer Science student at BPUT and Technical & Compliance Lead at **AkashVahini** (NIT Rourkela Incubated, MeitY GENESIS EIR 2.0 selected).

---

## ✨ Features

- **Pill Navigation:** Frosted glassmorphism header with active section spy and fluid scroll.
- **Dynamic Canvas Matrix:** HTML5 Canvas particle/tech grid background that responds to device dimensions.
- **Interactive Terminal:** Simulated developer boot CLI in the About section showing real-time command execution.
- **Indexed Projects Grid:** Cyberpunk-style `[01]`–`[04]` project architecture highlighting:
  - *SouryaNova* — AI-driven solar forecasting on AWS (Bedrock, Lambda, S3)
  - *Autonomous Drone Navigation* — Edge AI obstacle avoidance with Hailo AI & Raspberry Pi
  - *AI Exam Proctoring* — Real-time computer vision eye-tracking and pose estimation
  - *German Traffic Sign Classification* — Deep learning CNN built with Keras & TensorFlow
- **Skills Matrix:** 6 categorized skill blocks with neon-glow interactive pills.
- **Real-time Status Bar:** Live Indian Standard Time (IST) clock, coordinates (`RKL 22.26°N 84.87°E`), system availability indicator, and automatic night-shift amber mode.
- **Zero Dependencies:** Pure HTML/CSS/JS with zero build dependencies, 100/100 Lighthouse performance, and instant rendering.

## 🚀 Local Development

No package manager or build tool is needed. Simply open the file:

```bash
# Option 1: Open directly in your default browser
start index.html

# Option 2: Serve using any static server (e.g. Python)
python -m http.server 8000
```
Then visit `http://localhost:8000`.

## 🌐 Deploying to GitHub Pages

1. **Push to GitHub:**
   ```bash
   git init
   git add .
   git commit -m "feat: complete cyber-minimalist portfolio"
   git branch -M main
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
   git push -u origin main
   ```

2. **Activate Pages:**
   - Go to **Settings** > **Pages**
   - Source: **Deploy from a branch**
   - Branch: **`main`** / Folder: **`/ (root)`**
   - Click **Save**
